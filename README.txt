SPEARLION TECHS WEBSITE

FILES
- index.html: website content and structure
- styles.css: visual styling and responsive layout
- script.js: mobile navigation, reveal animations, year, and enquiry form

SETUP
1. Extract all website files into one folder.
2. Put these image files in the same folder as index.html:
   - Image_logo.jpg
   - Logo_bg.png
   - school.jpeg
   - pannel_review.png
   - Combo_Poster.png
   - Internship_Poster.jpg
3. Open index.html in Chrome, Edge, or Firefox.

IMPORTANT
Image filenames must match exactly, including capitalization and extension.
The enquiry form opens the visitor's email app and drafts an email to hello@spearliontechs.com. It does not store enquiries on a server. Verify the recipient address before publishing.
